# Plano de Marketing Digital: Pousada Vila Mathilde

Trabalho da aula 08 (Planejamento de Marketing Digital) para a Pousada Vila Mathilde, em Matilde, Alfredo Chaves (ES).

## Apresentação dinâmica
Abra `index.html` no navegador (ou pela página do GitHub Pages). Use as setas do teclado, o mouse ou o toque para navegar. Na matriz SWOT, nos objetivos SMART e no funil há elementos clicáveis.

## Público-alvo
Aposentado de terceira idade que busca sossego. Hoje a pousada recebe excursões de ônibus que vão e voltam no mesmo dia. O plano busca converter esse visitante em hóspede.

## Fontes
Briefing da pousada, deck da aula e diagnóstico de mercado. Persona, metas absolutas e preços atuais de Matilde são hipóteses a validar com o dono.
